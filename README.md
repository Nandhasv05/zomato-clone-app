# 🍔 Zomato Clone

### 🍕 Food Delivery Frontend UI

A frontend **Zomato-inspired food delivery website** built using **HTML5 and CSS3**.

The project focuses on recreating the visual structure of a modern food-delivery platform and demonstrates frontend fundamentals including layouts, navigation, restaurant sections, images and responsive styling.

# ✨ Features

* 🍔 Food delivery interface
* 🏪 Restaurant-style sections
* 🍕 Food categories
* 🖼️ Food and restaurant images
* 📍 Location-oriented UI
* 🔍 Search-style interface
* 🎨 Custom CSS design
* 📱 Responsive layout
* 🔗 Navigation sections

> This project is a frontend UI clone and does not implement real food ordering, payments or restaurant APIs.
